Where results go
Each file gets a JSON sidecar beside it (clip.mp4 → clip.mp4.json) with its tags, description and when each appears. The sidecar is also how the app knows a file is done: a changed file is analyzed again. In a read-only folder the sidecar goes under the data folder instead. More outputs (a JSONL file, your own plugin) are set with OUTPUT_SINKS; see docs/plugins.md.
Active outputs
Output language
Languages other than English are machine-translated and may contain mistakes. Each language downloads once (about 300 MB).
Re-analysis
Redo files analyzed by a different model Off: a file with results is done, whichever model produced them. On: results from another model (for example after an upgrade) count as not done. Never automatic.

First-time setup

VLM Media Tagger analyzes media with a local AI vision model (about 22 GB; it needs a Mac with 32 GB of memory or more).

It is downloaded once, onto this Mac — nothing is sent to any cloud service. Quitting is safe: the download resumes.
